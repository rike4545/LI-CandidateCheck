# LI-CandidateCheck

Independent, source-by-source reviews of the claims Long Island candidates make on their own campaign websites. It covers every 2026 New York State Senate and Assembly race in Nassau and Suffolk counties, with the same method and rating scale for every candidate.

**🌐 Live site: [rike4545.github.io/LI-CandidateCheck](https://rike4545.github.io/LI-CandidateCheck/)**

- **Races:** a district grid for all 31 races. Pick one to see both candidates side by side.
- **Compare:** any two candidates head to head, with rating tallies and claims in parallel columns.
- **Dashboard:** ratings across every review, filterable by chamber, county, party and incumbency, plus a search across all claims.
- **Shareable links:** every race, candidate, comparison and search has its own link.

> Scope: these reviews test whether each claim is **verifiable** and **accurate as stated**. They do not rate candidates, endorse anyone, or judge policy positions. Campaign pages differ a lot in length and type (an incumbent's record, a challenger's biography), so raw counts are not a like-for-like score. See [METHODOLOGY.md](METHODOLOGY.md#comparing-reviews).

## Ratings key

✅ Verified · 🟡 Verified with caveat · 🟠 Overstated / partly accurate · ⚪ Unverified (no public record found, which is not a finding that the claim is false) · 🔵 Activity claim · ❌ False. Full definitions are in [METHODOLOGY.md](METHODOLOGY.md#ratings).

## Repo layout

```
races.json                    every race, its candidates, and sourced results
candidates/<slug>/meta.json   page reviewed, bottom line, findings (hand-written)
candidates/<slug>/claims.csv  the claims ledger (hand-written)
candidates/<slug>/README.md   generated: summary + scorecard + ledger
site/template.html            the live site (HTML/CSS/JS, no dependencies)
docs/                         generated: what GitHub Pages serves
build.py                      validates the data and generates everything above
```

To add or update a review, edit `meta.json` / `claims.csv` and run `python3 build.py`. The build refuses to run if a row is malformed, a rating or category is unknown, or a candidate isn't listed in `races.json`. Never edit generated files by hand.

Corrections are welcome. Open an issue with a source.
